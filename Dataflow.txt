DataAccess Layer:
-> Repository lấy dữ liệu từ database.
-> DAO để xử lý truy vấn SQL phức tạp nếu cần.
BusinessLogic Layer:
-> Nhận yêu cầu từ Controller.
-> Gọi Repository để thao tác dữ liệu.
-> Xử lý logic nghiệp vụ (ví dụ: kiểm tra quyền, validate dữ liệu).
Presentation Layer (StudentNameMVC):
-> Gửi yêu cầu từ View lên Controller.
-> Controller gọi Service xử lý data.
-> Trả về View.
